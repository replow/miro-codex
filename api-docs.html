随机图片 API

无需密钥。每次请求都会从 Ronova 图库中随机挑选一张图片，并将访问者跳转到图片地址。也可以用查询参数按比例筛选。

接口地址

使用 GET 或 HEAD 请求以下地址：

GEThttps://ronova.top/api

接口会返回 302 Found，并通过 Location 响应头指向随机图片。浏览器、图片标签和支持自动跟随跳转的客户端会打开最终图片。

按比例获取

在地址后添加参数，可以限定随机图片的方向：

GEThttps://ronova.top/api?landscape

随机获取横向图片。

GEThttps://ronova.top/api?portrait

随机获取纵向图片。

GEThttps://ronova.top/api?square

随机获取接近正方形的图片。

GEThttps://ronova.top/api?name=文件名

获取指定图片，例如 ?name=ronova-arrival.webp。

<img src="https://ronova.top/api?landscape" alt="Ronova 横图">

直接使用

在网页中把 API 地址作为图片来源即可，浏览器会跟随跳转：

<img src="https://ronova.top/api" alt="Ronova 随机图片">

访问 /api 也可以直接打开一张随机图片。

命令行示例

查看跳转响应：

curl -I https://ronova.top/api

跟随跳转并保存最终图片：

curl -L https://ronova.top/api -o ronova.jpg

响应中包含 Cache-Control: no-store，以避免缓存随机选择结果。

响应与限制

302 Found
成功选择图片。请读取 Location 或让客户端自动跟随跳转。
400
方向参数无效。请使用 ?landscape、?portrait 或 ?square。
404
图库中没有可用图片，响应 JSON：{"error":"No images found. Add images to public/photos/."}
405
不支持该请求方法；允许的方法为 GET 和 HEAD。

该接口不启用跨域访问（CORS）。第三方网页如需通过 JavaScript 读取跳转响应，请由自己的后端发起请求；同源页面、普通链接和 <img> 可直接使用。

添加图片

把 JPG、JPEG、PNG、WebP、GIF 或 AVIF 图片放进仓库的 public/photos/ 目录，然后重新构建并部署。图库页面和随机图片 API 会自动使用这些图片。
